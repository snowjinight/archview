# §14 直方图专项（Ctrl+H）

> 机制 / 决策 / 不变量见 [ARCHITECTURE §6.5](../架构设计/06_图片预览模块.md)。
> 本文只记实现细节、方案取舍过程与踩坑。

## 1. 需求与方案取舍

需求：Ctrl+H 显示当前图片直方图，16/12/14bit 数据统一压缩到 0-255（全量程
均匀映射，非 clamp 舍弃高位）。

评估过三条路：

| 方案 | 结论 |
|---|---|
| 单图 raw 改路由走软解显示（"已实现软解的类型走软解，其余 mpv 兜底"） | **否决**。显示链不必要改道：软解 YUV 是固定 BT.601 系数，mpv swscale 是 flag 感知转换（精度回退）；多帧 raw 播放/seek 丢失；为直方图一个功能凿开 13 渲染架构的 mpv 单平面定位 |
| mpv 侧取像素（render FBO glReadPixels / vf histogram） | **不可行**。回读昂贵且 FBO 由 mpv render context 管理；vf histogram 是 overlay 型，统计值不通过 API 暴露 |
| **采用**：显示路径不动，直方图旁路取像素 | 标准图片在解码 worker 顺手算；raw 用 HistService 按需软解第 0 帧只算不传纹理 |

rawdec 此前已有两个消费者（mpv 拼参 extract.rs / 对比栏 compare.rs），
直方图是第三个——HistService 落在 rawdec 内部不另起新文件，符合
"≥2 消费者才独立成模块"的内聚原则。

## 2. 实现要点

### 2.1 imgview：解码 worker 顺手算

- `Histogram`（`ch: [[u32; 256]; 4]`，R/G/B/亮度）在 `request()` 的解码线程
  计算：`Decoded::Static` 全图 / `Anim` 取首帧（逐帧统计成本随帧数线性涨，
  且直方图语义是"这张图长什么样"）；
- 经 `ImgMsg::Ready.hist` 随解码结果回 UI 线程，存 `Cached.hist`，**随纹理
  同生命周期进 LRU**（每图 ~4KB，逐出即弃）；
- 访问器 `histogram(key)` 只读旁路，不触 LRU 时序（不像 `frame()` 提队首，
  不干扰翻页保护语义）。

### 2.2 rawdec：HistService

- `request()` 先走 `raw_demux_opts` + `raw_frame_info`（纯配置判定，不读
  文件）：预设未命中 → 直落 Err("非 raw…")；pixfmt 不在软解名单 → 直落
  Err——**不发线程**，覆盖层直接显示状态文案；
- 命中才 spawn `rawhist` 线程：`decode_raw_frame(source, info, 0)` →
  `Histogram::compute`，mpsc 回 UI，`request_repaint` 唤醒（事件驱动，
  无轮询）；
- 直方图与屏幕显示**逐位一致**：同一位移（`shift_u16_le`）+ 同一转换器
  （bayer demosaic / nv12 BT.601）——不会出现"直方图说的和看到的不一样"；
- 开关关闭时 `retain(&[])` 清缓存，长会话不驻留历史 key。

### 2.3 UI 层

- [nav.rs](../../src/ui/nav.rs)：`Key::H if m.ctrl`，`config_editor` 打开时
  让位（打字密集窗口）；开关本身无门控——未播放时按下只翻状态，覆盖层
  不绘制无副作用；
- [panels.rs](../../src/ui/panels.rs) `paint_histogram`：挂在 `video_area`
  两分支末尾（render API 单平面下 shape 提交顺序天然盖在 PaintCallback
  画面上）；borrow 分离——先克隆当前条目快照（id/stream/name/size）再做
  `&mut` 服务调用；
- 绘制：左下角 320×150 半透明底板，亮度白色低透明填充 + R/G/B 折线，
  归一化取四通道全局最大 bin（`max_bin` 空图兜底 1 防除零）。

## 3. 踩坑

### 3.1 直方图轮廓非凸，convex_polygon 错剪

egui `Shape::convex_polygon` 假设凸多边形，直方图轮廓普遍非凸——填充会被
错误剪裁。改用**逐 bin 三角带 Mesh**：`Mesh::default()`（无纹理纯色）+
`colored_vertex`（每 bin 顶/底两点）+ 相邻四边形索引，256 bin 稳定正确。

### 3.2 Color32 存储为预乘 alpha

`ColorImage::from_rgba_unmultiplied` 内部预乘：半透明像素的 RGB 是乘过
alpha 的暗值，直接计 bin 会系统性偏暗。`Histogram::compute` 对 `a<255`
像素先去预乘（`r*255/a`）还原原色；不透明图（照片主流）零开销直通。
注意预乘取整有 ±1 误差（128 半透明白还原后 127 而非 128），断言用窗口
匹配而非精确值。

### 3.3 egui 0.36 const 上下文限制

`Color32::from_rgba_unmultiplied` 不是 const fn——数组常量里用会 E0015。
折线透明度改用 `gamma_multiply(0.86)`（同样是运行期调用，放局部 `let`）。

## 4. 测试

- `imgview::tests::直方图_分箱与预乘还原`：不透明/半透明/全透明像素分箱、
  去预乘窗口匹配、每通道计满像素总数；
- `imgview::tests::直方图_空图防除零`：全黑图 / 零像素图 `max_bin` 兜底；
- `rawdec::tests::hist_service_非raw与预设错误直落结果`：标准视频名直落
  "非 raw" 文案、坏 pixfmt 直落预设错误、`retain` 清理语义；
- Ctrl+H 按键臂无 App 级测试：`handle_shortcuts` 需要 `&mut eframe::Frame`
  （测试不可构造），与既有快捷键同状态——靠编译器保证臂存在。
