## 6. 测试运行方式与覆盖矩阵

> 从 README 迁入（用户向文档只保留用法与配置）。会话化专项断言明细见[本文 §5](05_解压会话化回归测试.md)。

### 6.1 运行方式

```bat
run_tests.bat
```

或直接：

```bat
cargo test -- --nocapture
```

### 6.2 覆盖矩阵

| 测试 | 验证内容 |
|---|---|
| VFS 单元测试 | ZIP / 7Z / RAR 各自的列表、读取、seek 正确性；7Z 测试包由 sevenz-rust 纯代码构造，无外部依赖 |
| DirVFS 单元测试 | 目录媒体集合：递归收集与字典序确定性（跳过压缩包/非媒体）、条目读取与 seek 正确性、未知条目报错与空目录空集合、根不可读报错 |
| 目录模式集成（UI 层） | spawn_open 目录分支真实线程链路（DirVFS::open → stream_cb 注册 → Done 消息）、打开终态状态迁移（FastSeek→stream 标志/视图重建）与空目录统一提示 |
| e2e 流式播放 | headless mpv（vo=null ao=null cache=no）经 zvf:// 协议真实播放 deflate ZIP 内的 mp4，验证下游 / 上游 seek，以及 EOF 后切换视频能正常续播（keep-open 暂停粘滞回归，见 [§3.0](03_播放流畅性专项.md) 备忘） |
| e2e 解压播放 | 构造 7Z 包 → 后台解压 → headless mpv 播放本地文件全链路 |
| flag 属性循环 | pause / mute 属性经 flag 格式读 → 翻转 → 写 → 读，覆盖空格暂停、静音按钮的行为路径（FLAG 格式约定见 [§3.0](03_播放流畅性专项.md) 备忘） |
| VarTidy | 分类规则（五类非法+合法路径）、仓库只读三道闸（含 rename 不覆盖）、两级去重（CRC 判重）、密码候选链路（AES zip / 7z 加密头与内容加密 / 同批次多包各不同密码乱序命中 / 中文与特殊字符密码）、中文/空格/特殊字符作者名与包名全链路 |
| 滑动窗口冒烟（UI 层） | 模拟用户批内来回跳动 0→1→0→2→（解净空闲）→5→0：断言解码线程全程不重启（cancel 句柄同一性）、预取窗口随观看位置滑动、缓存命中立即播放、全部落地文件逐字节内容校验（明细见 [§5.2](05_解压会话化回归测试.md)） |
| config | TOML 默认模板与代码默认值防漂移、序列化往返、特殊字符密码（`#`/空格/中文）引号保留 |
| RAW 媒体 | config：pixfmt 名单数量快照与容器位数口径、raw 可见性预设唯一入口（`is_video_ext = video_extensions 命中 ∨ raw_demux(name)`，`raw.extensions` 清单已移除）与 glob 匹配、默认模板含 [raw] 节；imgview：RAW 扩展名判定（裸名不误伤）、垃圾字节 fall through、EXIF 八方向映射；ui：raw_demux_opts 四类拦截（pixfmt 名单 / 宽高为 0 / 文件大小不整除帧字节 / bit_shift 越界或非 le）+ 无预设非标名不拦截交 mpv 的文案与拼参格式；player e2e：ffmpeg 造 nv12 → rawvideo 选项装载 → 起播/时长=帧数÷fps/尺寸/帧精确 seek + 装载失败事件与日志链路（外部依赖 ffmpeg，缺则跳过，坑见 [§8.3](08_RAW媒体支持专项.md)） |

### 6.3 headless e2e 原理与外部依赖

e2e 测试不需要人工看画面：mpv 以无渲染模式运行，通过 `time-pos` / `pause` /
`eof-reached` 等属性断言播放状态，`cache=no` 强制 seek 请求打到 VFS 层，能真实
暴露流实现缺陷。

外部依赖三条（**本机工具位置**，换机时改探测 fallback 或设环境变量）：

- **RAR 测试**需要本机装有 WinRAR（探测环境变量 `ARCHVIEW_TEST_RAR` 或
  Program Files 常见路径，找不到自动跳过，不算失败）——
  本机在 `C:\Program Files\WinRAR`（rar.exe/UnRAR.exe 均在此，标准位置可自动探测）；
- **ffmpeg/ffprobe**（player e2e 造数据 / encode e2e 精确帧数断言）——
  本机在 `D:\11_software`（**不在 PATH**）。encode 侧探测顺序：
  PATH → `ARCHVIEW_TEST_FFMPEG` 环境变量（目录或 exe 完整路径均可）
  → 硬编码 fallback `D:\11_software\ffprobe.exe`（换机改
  `src/encode/mod.rs` 的 `ffprobe_exe()`）。
  player e2e 侧暂仍 PATH-only，跑前需临时
  `$env:PATH = "D:\11_software;$env:PATH"`（后续可统一到 ffprobe_exe 模式）；
- **VarTidy 本地冒烟环境**：`test_tidy\setup.bat`（目录已 gitignore）一键全链路
  ——构建 → `cargo run --example make_smoke_fixtures` 生成 6 个测试包
  （明文/AES zip/明文/内容加密 7z/特殊字符密码 + 既有仓库）→ dry-run →
  实际整理（加密包打开期即锁定密码）→ 幂等重跑。
