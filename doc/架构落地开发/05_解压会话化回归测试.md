## 5. 解压会话化回归测试细节（[ARCHITECTURE §11.4](../架构设计/11_性能优化与虚拟列表.md) 的测试断言明细）

> 真暂停（批完成驻留）落地后全部改写为**驻留语义**驱动：线程不再因 targets 解空
> 退出，断言方式从"等退出"改为"等解净 + cancel 收尾"。

### 5.1 解码线程侧单测（sevenz_vfs.rs，5 个，全部驻留语义）

- 共同驱动 helper `run_session_until_drained`：后台线程跑 `extract_session` 闭包，
  主线程等 targets 清空后置 cancel 收尾——真暂停后线程驻留不退出，必须由 cancel
  断言 `Err(Cancelled)` 收尾（"解净"不再是可观察的退出事件）。闭包 move + 外层
  `Arc<Mutex>` 收集结果、`Arc<SevenzVFS>` clone 传递 vfs；
- `session_lifecycle_and_reuse`：① 目标解净 → 批完成驻留（targets 清空、线程等待）
  由 cancel 收尾；② 空目标再入 = 驻留等待直至 cancel（`Err(Cancelled)`），期间不触碰
  任何文件（旧语义"空目标立即返回 Ok"已废除）；复用时 focus 抢道落地顺序 [3,0] /
  脏目标 `Err(Archive)`；
- `session_zero_landing_rescued_by_gen`：65 条目 solid 包中途重定向 → 本轮零落地 →
  gen 0→1 救回重新规划解出新目标而非误报 Err；
- `session_dynamic_targets_chain`：回调链式追加 → 单次调用解出全部四个（断言不变，
  驱动改 helper）；
- `session_focus_drift_interrupts_folder`：solid folder 内切 focus → 漂移中断 →
  自愈补齐，落地顺序 [g1, h1, g3] 且三文件内容全验证（驱动改 helper）。

### 5.2 UI 层冒烟测试（ui/tests.rs `sliding_window_smoke_in_batch_back_and_forth`）

模拟用户批内来回跳动：不走 egui 渲染，直接驱动 `start_extract` + 轮询
`poll_extract` 模拟 UI 主循环（测试构造器 `new_for_test` 绕开
`eframe::CreationContext`；`start_extract`/`poll_extract` 不依赖 frame 参数，
天然可测）。6 × 1MB 伪随机 jpg 压成单 folder solid 7z，下游预取 3MB
（`prefetch_downstream_mb=3`）使窗口恰为 [目标, +1, +2]、上游预取关闭
（`prefetch_upstream_mb=0`）让断言值可硬编码；跳转链
0→1→0→2→1→0→（批完成驻留）→5→0 覆盖全部分支：

- 批内切换以 `Arc::ptr_eq(cancel)` 断言解码线程**不重启**且 `started` 不清零
  （覆盖层宽限期不清零）；
- 回跳已落地目标（点击项在锚点上游）走 keep——立即播放且**会话纹丝不动**
  （窗口/focus/gen/pending 快照对比全等、cancel 同句柄），连点多个缓存项
  （点 1 再点 0）仍全 keep（复现"点完 10 再点 11"场景：绝不触发窗口重建）；
- 向下游点击未落地项才重定向滑窗 + 锚点向下游推进 + gen 自增；
- **解净 = 批完成驻留而非退出**：drained 条件改为 `j.idle && 会话 alive &&
  targets.is_empty()`；随后点击复用同一线程（cancel 句柄 `Arc::ptr_eq` 断言
  不重启）；整窗已落地不重定向、focus 不回退；
- 终态 = 会话存活驻留（`alive == true`）+ `j.idle` 置位 + 6 文件逐字节与源数据
  比对（防落地错位）——不再断言"会话干净退出"。1MB 文件解码为百 ms 级而断言
  紧跟落地事件（μs 级），窗口期约千倍差，时序不抖。
- 测试夹具 `mk_job` 构造补 `idle: false` 字段（ExtractJob 新字段）。
