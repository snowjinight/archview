## 16. 多图对比视图

文件列表多选 2~6 个条目分栏同时显示：多栏同步缩放 / 平移对比。非标 raw dump
（[[raw.demux]] 预设命中）与静态图混选均可入栏——raw 栏走软解帧提取（不走
mpv），多帧 raw 共享帧游标逐帧比对。实现：UI 组合在 `src/ui/compare.rs`，
raw 媒体能力（预设校验 / Bayer 探测 / 软解帧提取 / RawFrameService）在
`src/rawdec.rs`（媒体层，与 imgview.rs 平级，mpv 播放路径与对比路径共同消费）。

分层定位：**UI 层组合功能 + ImageService 扩展，VFS 层零改动**——各栏只是
同一 VirtualFile 流的并列消费者。与既有系统的关系：

| 复用 | 说明 |
|---|---|
| 文件列表多选（§11.5 系） | 原为 encode 批量选择服务的选择集，直接作为对比入口选择 |
| ImageService 纹理路径 | 新增 `shown_multi` 多键驻留（LRU 逐出保护）+ `frame_ex` 指定键取帧 |
| raw 预设参数（§13.6） | raw_demux_opts 校验 + 文件名分辨率兜底 + bayer 自动探测全量复用 |
| 解压会话（§11.4） | 非流式包仅主栏触发 start_extract，solid 滑窗顺带解出其余栏 |

### 16.1 同步语义（方案 A：相对 fit 的倍率 + 归一化坐标）

不同分辨率图要"内容对齐"地同步缩放平移，缩放量和平移量都不能用绝对像素：

- **共享缩放 `zoom: Option<f32>`** = 相对各栏 fit 的倍率。None = 各栏适应
  窗口；Some 底界 1.0 = fit，顶界 MAX_ZOOM。**对比模式无 100% 语义**——
  各栏 fit 基准不同，"100%" 失去单一含义，因此没有 0 键；
- **共享平移 `center: egui::Vec2`** = 视口中心指向的归一化图像坐标
  （0.5,0.5 = 居中）。同一 center 在各栏按各自 disp 换算屏幕矩形
  （`pane_image_rect`：中心 = vp.center + (0.5 − center)×disp），
  不同尺寸图自动对齐同一点；
- **钳制 `clamp_center`**：大图（显示尺寸 > 栏视口）不露边，小图归中居中——
  与单图模式 clamp_pan 同构，坐标系换成归一化；
- **锚点缩放 `sync_zoom_center`**：以交互栏（主栏）disp 推导，锚点图像坐标
  缩放前后不动（center' = center + delta×(1/db − 1/da)）。center 是共享
  归一化量，其余栏自动跟随；
- **步进 `sync_zoom_step`**：×1.25；缩到 fit 及以下落 None；fit 态只放大。
  缩放底界落 fit 时 center 回归 (0.5, 0.5)。

不变量：**zoom/center 是会话级共享状态，任何一栏的交互（拖拽 / 滚轮锚缩放）
都读写同一份**；主栏只决定锚缩放的 disp 取值，不产生独立视图状态。

### 16.2 滑动窗口模型

对比栏集合不是固定选中集，而是 `domain` 快照上的滑动窗口：

- **domain** = 进入对比时 `view ∩ 入口谓词` 的索引快照（按视图序）。搜索 /
  切标签改变 view 时快照不重建（对比是模态，列表交互不在场）；
- **初始窗口** = 选中合格项（可散点、非连续）；**首次组滑动后吸附为连续
  窗口**（`slide_window` 从首栏在 domain 中的位置起连续取 N 个）；
- **组滑动**（PgUp/PgDn / fit 态滚轮）：窗口整体 ±1，越界不动；
- **栏数切换**（数字键 2~6）：缩小保前 N 栏；放大走 `grow_window`（从窗口
  末栏之后追加 domain 条目，跳过已在窗口中的），一条都加不了提示"条目不足"。

不变量：**窗口长度 = 栏数，成员 ⊆ domain**；散点初始选中项只在首次滑动前
存在，滑动后永远连续。

### 16.3 入口谓词与模态边界

`compare_eligible`：静态图（`is_image_ext` 且非 gif/动画 webp）∨ raw 预设
命中。**标准视频不参与**——对比模式 mpv 完全不在场，无播放语义可对齐。

入口：选中态 **C 键** 或右键菜单「对比显示（C）」。合格数 <2 提示不放行；
>6 取视图序前 6 张 + 提示。进入对比时 `player.stop()`、playing/slideshow/
hold_img 全清——**对比与播放互斥，不是叠加态**。

### 16.4 双解码路径：纹理直显 / 软解帧提取

| 栏类型 | 路径 | 说明 |
|---|---|---|
| 静态图 | ImageService `frame_ex(key, is_master)` | 与单图模式同一条纹理链路；非主栏传 `is_master=false` 防 full 高清槽被逐帧抖掉；full 升级仅主栏触发（判据同 image_view） |
| raw dump | RawFrameService 软解 | 每请求 spawn "rawdec" 线程（catch_unwind 兜 panic）+ mpsc 回 UI 上传纹理；`frames` 保留旧帧无闪烁、`errs` 确定性失败不重试、`pending` 防重复请求 |
| raw 参数错误 / 不支持格式 | `PaneKind::RawErr` 占位文案 | 不阻塞其它栏 |

raw 软解 = 播放路径同一套参数语义（pixfmt / bit_shift / bayer 探测 / 帧数 =
size/frame_bytes），全部住在 `src/rawdec.rs`：nv12（BT.601）、gray、
gray16le、bayer_*16le（双线性 debayer，相位偏移表 `bayer_offsets` 预计算）、
bayer_auto16le 装载前探测（`resolve_auto_bayer`，mpv 播放路径同一函数）。
帧 N = k×frame_bytes 精确 seek（`shift_u16_le` 与 stream_cb::ShiftReader
同语义，位移逐位一致）。

**共享帧游标 `cursor`**：会话含多帧 raw 栏时 ←/→ 移动游标，各栏钳制到自身
frame_count−1，badge 显示 "cur/count" 错位——**不要求所选文件帧数相同**；
纯静态会话 ←/→ 兜底为组滑动（判据 `has_multi_frame_raw` 是确定性谓词）。

### 16.5 源就绪闸门与解压会话联动

`source_ready`：流式条目恒可读；非流式（7z/RAR）条目必须已完整落地
（dest 文件 len == size）。**半截文件发起解码必然失败，且两个解码服务的
失败都是确定性的**（ImageService 记 img_fallback、RawFrameService 记 errs
不再重试）——落地检查前置是防确定性失败污染缓存的统一闸门。

非流式包解压策略：**仅主栏触发 start_extract**；solid 包 compute_batch
滑窗顺带解出其它栏，single-file 包其它栏显示等待文案。主栏落地检测
（master_landed==false 且无密码框 / 无错误 / 未覆盖）触发解压会话，
落地后自愈（filter source_ready 重新发起解码请求）。

### 16.6 对比模态键表与播放劫持防护

对比是**独立第三个快捷键模态**（`compare_shortcuts`，nav 分派在主键表之前
短路返回）：无修饰键生效；搜索框聚焦整体让位。

| 按键 | 功能 |
|---|---|
| PgUp / PgDn | 整组滑动 ±1（6 栏满时翻页即整组换血） |
| ← / → | 多帧 raw 会话 = 帧游标 ±1；纯静态 = 组滑动兜底 |
| 数字键 2~6 | 切换栏数（窗口宽度语义） |
| + / − / Home | 共享缩放 / 回 fit |
| 滚轮（fit 态） | 整组滑动（wheel_switch_secs 节流） |
| 滚轮（缩放态或 Ctrl） | 悬停栏锚缩放（一个滚轮事件只消费一次） |
| Esc | 全屏中先退全屏，再退对比；退出对比回放主栏 |
| 单击某栏 | 设为主栏（full 升级跟随） |

播放劫持防护（三处守卫）：`play()` 顶部清 compare（对比态任何 play 调用
先退对比）；`poll_extract` 的 FileDone 自动播放与 Done 兜底补播加
`compare.is_none()` 守卫——对比会话触发的解压会话不得反向劫持回播放。

### 16.7 布局

固定映射（不加布局配置项）：2=1×2、3=1×3、4=2×2、5=3+2（上 3 下 2）、
6=3×2，gap 2px。徽标：每栏左上角帧游标 "cur/count"（多帧 raw 栏）、
左下角文件名 + 主栏 ★（琥珀色，与选中行 S 标志同色系）。
