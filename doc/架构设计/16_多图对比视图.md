## 16. 多图对比视图

文件列表多选 2~6 个条目分栏同时显示：多栏同步缩放 / 平移对比。非标 raw dump
（[[raw.demux]] 预设命中）与静态图混选均可入栏——raw 栏走软解帧提取（不走
mpv），多帧 raw 共享帧游标逐帧比对。实现：UI 组合在 `src/ui/compare.rs`，
raw 媒体能力（预设校验 / Bayer 探测 / 软解帧提取 / RawFrameService）在
`src/rawdec.rs`（媒体层，与 imgview.rs 平级，mpv 播放路径与对比路径共同消费）。

分层定位：**UI 层组合功能 + ImageService 扩展，VFS 层零改动**——各栏只是
同一 VirtualFile 流的并列消费者。与既有系统的关系：

| 复用 | 说明 |
|---|---|
| 文件列表多选（§11.5 系） | 原为 encode 批量选择服务的选择集，直接作为对比入口选择 |
| ImageService 纹理路径 | 新增 `shown_multi` 多键驻留（LRU 逐出保护）+ `frame_ex` 指定键取帧 |
| raw 预设参数（§13.6） | raw_demux_opts 校验 + 文件名分辨率兜底 + bayer 自动探测全量复用 |
| 解压会话（§11.4） | 非流式包仅主栏触发 start_extract，solid 滑窗顺带解出其余栏 |

### 16.1 同步语义（方案 A：相对 fit 的倍率 + 归一化坐标）

不同分辨率图要"内容对齐"地同步缩放平移，缩放量和平移量都不能用绝对像素：

- **共享缩放 `zoom: Option<f32>`** = 相对各栏 fit 的倍率。None = 各栏适应
  窗口；Some 底界 1.0 = fit，顶界 MAX_ZOOM。**对比模式无 100% 语义**——
  各栏 fit 基准不同，"100%" 失去单一含义，因此没有 0 键；
- **共享平移 `center: egui::Vec2`** = 视口中心指向的归一化图像坐标
  （0.5,0.5 = 居中）。同一 center 在各栏按各自 disp 换算屏幕矩形
  （`pane_image_rect`：中心 = vp.center + (0.5 − center)×disp），
  不同尺寸图自动对齐同一点；
- **钳制 `clamp_center`**：大图（显示尺寸 > 栏视口）不露边，小图归中居中——
  与单图模式 clamp_pan 同构，坐标系换成归一化；
- **锚点缩放 `sync_zoom_center`**：以交互栏（主栏）disp 推导，锚点图像坐标
  缩放前后不动（center' = center + delta×(1/db − 1/da)）。center 是共享
  归一化量，其余栏自动跟随；
- **步进 `sync_zoom_step`**：×1.25；缩到 fit 及以下落 None；fit 态只放大。
  缩放底界落 fit 时 center 回归 (0.5, 0.5)。

不变量：**zoom/center 是会话级共享状态，任何一栏的交互（拖拽 / 滚轮锚缩放）
都读写同一份**；主栏只决定锚缩放的 disp 取值，不产生独立视图状态。

### 16.2 滑动窗口模型

对比栏集合不是固定选中集，而是 `domain` 快照上的滑动窗口：

- **domain** = 进入对比时 `view ∩ 入口谓词` 的索引快照（按视图序）。搜索 /
  切标签改变 view 时快照不重建（对比是模态，列表交互不在场）；
- **初始窗口** = 选中合格项（可散点、非连续）；**首次组滑动后吸附为连续
  窗口**（`slide_window` 从首栏在 domain 中的位置起连续取 N 个）；
- **组滑动**（PgUp/PgDn / fit 态滚轮）：窗口整体 ±1，越界不动。**就绪
  闸门**：Incoming（新入栏条目）纹理未就绪且"就绪在路上"（流式解码在途 /
  非流式文件已落地解码中或解压会话已排期）时**挂起整组滑动**
  （`pending_slide`，compare_tick 轮询就绪后自动滑）——换屏瞬间全栏一致，
  不出现"末栏等待落地"的割裂感；就绪路径消失（解码失败 / 会话不覆盖）
  则放弃挂起立即滑动，栏内占位文案兜底。挂起不排队，重复按键 = 最新意图。
  **提示延迟化**：挂起本身静默（快滑百毫秒级完成，提前提示只会闪现误导），
  等待超 300ms 才上屏"预取下一组中"（`pending_slide` 携带挂起时刻 + 已提示
  标记）；
- **双向预取**：窗口前/后各 1 张合格静态图（**栏数+1 语义，6+2**——Incoming
  恒在其中；稳态翻页延迟由就绪闸门 + 解码耗时吸收，不为连续快翻预驻一整组
  纹理）。**窗口优先、预取让路**：候选一律只记键，窗口栏全部就绪（landed
  图片栏无在途解码）后由 compare_tick 统一补发（含流式）——慢盘上预取流的
  随机读不与正在等待的窗口栏交错（同 §13.7 单图预取串行链哲学；窗口栏本身
  不串行——对比模式无"当前张"，整组时间并行 = max(单张) vs 串行 = Σ(单张)，
  且发起序按 domain 序、包内物理相邻已是准顺序读；raw 栏 rawdec 队列本就
  单 worker 串行不参与闸门）。候选与窗口一起进 `shown_multi` 逐出保护集
  （换屏时 Incoming 恒命中缓存）；
- **栏数切换**（Z/X 步进）：X=加一栏（上界 6，走 `grow_window` 从窗口末栏
  之后追加 domain 条目，跳过已在窗口中的，一条都加不了提示"条目不足"）；
  Z=减一栏（缩小保前 N 栏），**下界 2，2 栏再减 = 自然退出对比模式**
  （回落播放主栏条目，与 Esc 退出同一路径）。数字键 1-5 让位给评主栏
  （16.6），栏数由占用 5 个平键改为 ±1 步进。

不变量：**窗口长度 = 栏数，成员 ⊆ domain**；散点初始选中项只在首次滑动前
存在，滑动后永远连续。

### 16.3 入口谓词与模态边界

`compare_eligible`：静态图（`is_image_ext` 且非 gif）∨ raw 预设命中。
**标准视频不参与**——对比模式 mpv 完全不在场，无播放语义可对齐。

gif 恒为动图按名排除；**webp 静态/动画按名不可分**，按名放行后在窗格构建
时以 VP8X 头嗅探（`webp_animated`，image crate `WebPDecoder::has_animation`
与 imgview 解码分流同一判据）分流：静态 webp 正常入栏，动画 webp 落
`PaneKind::Unsupported` 占位文案（滑动窗口把动画 webp 带进窗格时同样命中）。
嗅探失败（打开/解析失败）一律按静态处理——不可误拦静态图，失败图交
ImageService 走正常失败路径。

入口：选中态 **C 键** 或右键菜单「对比显示（C）」。合格数 <2 提示不放行；
>6 取视图序前 6 张 + 提示。进入对比时 `player.stop()`、playing/slideshow/
hold_img 全清——**对比与播放互斥，不是叠加态**。

### 16.4 双解码路径：纹理直显 / 软解帧提取

| 栏类型 | 路径 | 说明 |
|---|---|---|
| 静态图 | ImageService `frame_ex(key, is_master)` | 与单图模式同一条纹理链路；非主栏传 `is_master=false` 防 full-slot 被逐帧抖掉；full 升级仅主栏触发（判据同 image_view），受 `image_compare_full_resample_enable` 开关控制（默认关，见 16.8） |
| raw dump | RawFrameService 软解 | 每请求 spawn "rawdec" 线程（catch_unwind 兜 panic）+ mpsc 回 UI 上传纹理；`frames` 保留旧帧无闪烁、`errs` 确定性失败不重试、`pending` 防重复请求 |
| raw 参数错误 / 不支持格式 | `PaneKind::RawErr` 占位文案 | 不阻塞其它栏 |
| 动画 webp（嗅探命中） | `PaneKind::Unsupported` 占位文案 | 不发起解码；滑动窗口带入时同样命中 |

raw 软解 = 播放路径同一套参数语义（pixfmt / bit_shift / bayer 探测 / 帧数 =
size/frame_bytes），全部住在 `src/rawdec.rs`：nv12（BT.601）、gray、
gray16le、bayer_*16le（双线性 debayer，相位偏移表 `bayer_offsets` 预计算）、
bayer_auto16le 装载前探测（`resolve_auto_bayer`，mpv 播放路径同一函数）。
帧 N = k×frame_bytes 精确 seek（`shift_u16_le` 与 stream_cb::ShiftReader
同语义，位移逐位一致）。

**共享帧游标 `cursor`**：会话含多帧 raw 栏时 ←/→ 移动游标，各栏钳制到自身
frame_count−1，badge 显示 "cur/count" 错位——**不要求所选文件帧数相同**；
纯静态会话 ←/→ 兜底为组滑动（判据 `has_multi_frame_raw` 是确定性谓词）。

### 16.5 源就绪闸门与解压会话联动

`source_ready`：流式条目恒可读；非流式（7z/RAR）条目必须已完整落地
（dest 文件 len == size）。**半截文件发起解码必然失败，且两个解码服务的
失败都是确定性的**（ImageService 记 img_fallback、RawFrameService 记 errs
不再重试）——落地检查前置是防确定性失败污染缓存的统一闸门。

非流式包解压策略：**仅主栏触发 start_extract**；solid 包 compute_batch
滑窗顺带解出其它栏，single-file 包其它栏显示等待文案。主栏落地检测
（master_landed==false 且无密码框 / 无错误 / 未覆盖）触发解压会话，
落地后自愈（filter source_ready 重新发起解码请求）。

### 16.6 对比模态键表与播放劫持防护

对比是**独立第三个快捷键模态**（`compare_shortcuts`，nav 分派在主键表之前
短路返回）：无修饰键生效（全局工具键 Ctrl+A/Q/S 在分派前已处理，见表首行；
其余带修饰键放行）；搜索框聚焦整体让位。

| 按键 | 功能 |
|---|---|
| Ctrl+A / Ctrl+Q / Ctrl+S | **全局工具键补位**（对比键表之前分派）：全选 / 清除全部选中 / 同步评级到文件。列表选择与评级同步与播放模式无关，必须两模态可达——对比模态短路 return 之前先处理（模态媒体键才归本表全权接管） |
| PgUp / PgDn | 整组滑动 ±1（6 栏满时翻页即整组换血；就绪闸门挂起详见 16.2） |
| 回车 | 全屏切换（通用键语义，对比模态全权接管故在此补位） |
| B | 回到锚点：滑动域含锚点条目时整组滑窗吸附到它并设为主栏（靠窗口中部），否则提示；zoom/center/cursor 保持 |
| N | 打开下一个压缩包（切换压缩包时对比会话随旧包清除） |
| 0 | 主栏 100%：zoom = 1/主栏 fit 缩放比（compare_view 每帧记录主栏 fit），其余栏按共享倍率内容对齐跟随——共享 zoom 无单一 100% 语义，锚定主栏换算 |
| 双击某栏 | 整组回适应（单图双击的"↔100%"半边由 0 键承担） |
| ← / → | 多帧 raw 会话 = 帧游标 ±1；纯静态会话不响应（组滑动专属 PgUp/PgDn 与 fit 态滚轮） |
| ↑ / ↓ | 整组缩放步进（与 +/− 同义，同单图模式心智） |
| 1~5 / Q | 评主栏星 / 清除主栏评级（与主键表同语义；主栏 = 最后点击的栏，raw 栏/占位栏不可评给提示）。存储链与单图共用 rate_ctx：目录模式延迟批量写、压缩包会话内记忆，列表 ★ 前缀即时亮起 |
| Z / X | 栏数 −1/+1 步进（原数字键 2~6 改步进，为评主栏让位数字键；2 栏再减 = 退出对比） |
| 空格 | 整组自动翻页开 / 关：间隔复用 `ui.slideshow_secs`，到期 `compare_slide(1)`（就绪闸门 / 末组停住语义免费复用）；窗口换血（自动/手动滑动、Z/X、B 回锚点）即重置计时，与单图幻灯片"手动切换重置"一致。开关状态在 CompareSession 内**随会话消亡**——退出对比不泄漏回单图幻灯片；排帧走 `compare_autoplay_rest` 精确唤醒（幻灯片类白名单主动排帧场景），无周期心跳。**控制栏 ▶/|| 中键与空格共用同一动作**（`compare_toggle_autoplay`，同状态同文案，两入口不漂移） |
| + / − / Home | 共享缩放 / 回 fit |
| 滚轮（fit 态） | 整组滑动（wheel_switch_secs 节流） |
| 滚轮（缩放态或 Ctrl） | 悬停栏锚缩放（一个滚轮事件只消费一次） |
| Esc | 全屏中先退全屏，再退对比；退出对比回放主栏 |
| 单击某栏 | 设为主栏（full 升级跟随，受 16.8 开关控制） |
| Ctrl+H | 直方图覆盖层开关（与单图模式共用同一开关状态，见 16.10） |
| W / S | per-file 显示对比度步进（全部栏同调，与单图模式同一条锚点 127.5 线性映射，见 6.3）：图片栏 natives 毫秒级重建纹理，raw 栏按 contrast 陈旧判定自动重解同帧；OSD 显示主栏倍率 |
| Alt+左键 | 像素探针：取点显示原图坐标 + RGB/YUV(BT.601)；raw 栏按格式显示存储原值，跨栏同步（见 16.9） |

播放劫持防护（三处守卫）：`play()` 顶部清 compare（对比态任何 play 调用
先退对比）；`poll_extract` 的 FileDone 自动播放与 Done 兜底补播加
`compare.is_none()` 守卫——对比会话触发的解压会话不得反向劫持回播放。

**列表高亮/滚动追踪主栏**：文件列表的高亮与居中滚动焦点统一走
`list_focus_idx()`——单图态 = playing，对比态 = 主栏条目（playing 在对比
态恒 None 不能直接用）。主栏语义 = 最后点击的栏：整组滑动时主栏**位置**
保持 → 高亮每页推进 1；单击某栏设主栏 / B 键回锚点吸附 → 高亮即时跟随；
退出对比回放主栏条目后 playing 无缝接管，追踪不跳变。

### 16.7 布局

固定映射（不加布局配置项）：2=1×2、3=1×3、4=2×2、5=3+2（上 3 下 2）、
6=3×2，gap 2px。徽标：每栏左上角帧游标 "cur/count"（多帧 raw 栏）、
左下角文件名 + 主栏 ★（琥珀色，与选中行 S 标志同色系）。
**主栏整栏琥珀描边**（1px Inside 收边）：当前主栏的整框视觉标识，与徽标
同色系，压栈绘制覆盖全部栏型（占位/错误栏也可为主栏）；主栏切换即时跟随。

### 16.8 主栏 full 重采样使能（image_compare_full_resample_enable，默认关）

对比模式主栏 full 升级判据与单图相同（16.4），但默认**关闭**：`[image]`
节 `image_compare_full_resample_enable`（默认 false）控制主栏深放大是否
触发 full 解码与选画 full 纹理。设计动机：对比的目的是同屏看差异，base 档
纹理（×ppp 预放大）已够用；full 档主栏与 base 档副栏锐度不一致反而干扰
判断，且主栏切换逐次触发 full 解码是纯开销。单图模式不受此键影响
（恒允许升级）。

### 16.9 像素探针（Alt+左键，跨栏同步）

静态图栏 Alt+左键取点：**过点小十字**（臂长 9px 的横竖两段线，交点即
取样点；黑衬底+白线保证任意背景可见）+ 悬浮信息文字（原图像素坐标 x/y +
RGB + YUV(BT.601)）。坐标机制同单图（归一化 uv 存储 + orig-lru 原图缓存取样，
见 §6.6）。

- **跨栏同步**：点击栏与目标栏**同类型且分辨率相同**才同步显示——同类型
  同分辨率下同一 uv 即同一像素坐标；类型不同（图像↔raw 读数语义不同）
  或分辨率不同则同一 uv 指向不同像素，只在点击栏显示。图像↔图像按
  orig-lru 原图尺寸比对，raw↔raw 按 RawFrameInfo 尺寸比对；
- **文字固定白字 + 黑色 8 向包边**（±1px）——不探测背景亮度，任何背景
  都可读；文字锚定探针右下 10px 尽量贴近，超界折回；
- **raw 栏按格式分流读存储原值**：raw 栏探针走 rawdec 按需读源（不做帧级
  转换缓存，每次点击后台线程从磁盘直读所需几个字节），按内建格式显示
  **文件存储原值**（未做 bit_shift 位移、未插值 RGB）：
  - **NV12**：YUV(x,y)——该点 Y + 覆盖它的 2×2 块共享的 U/V（4:2:0 半采样
    按 (x/2, y/2) 取）；
  - **GRAY**：GRAY(v, bits)——单点亮度值 + 有效位深（gray=8；gray16le
    位移后 = 16−bit_shift）；
  - **BAYER**：对齐 2×2 块的 4 个存储原值 + 排列名 + 位深（采样点对齐
    2×2 块；bayer_auto16le 伪格式先探测排列）；
  实现机制：rawdec::RawProbe 枚举 + RawMsg::Probe 消息通道（"rawprobe"
  后台线程）+ 服务端 probes 状态表（帧游标/uv 变化即重发，同帧同点幂等；
  在途显示"读取中…"）；
- **bayer 排列解析缓存（resolved 表）**：bayer_auto16le 的排列解析 = 整帧
  读 + 全图统计（24MP 16bit 一帧 48MB），而排列只依赖数据内容**整包不变**
  ——RawFrameService 按 key 缓存落定 pixfmt，首请求（帧解码或探针谁先到
  都算）解析后探针与帧解码两链路共用，后续点击/切帧零探测成本；多栏对比
  一次点击 N 栏不再付出 N 份整帧探测。缓存随 retain（退出对比/窗口滑动）
  清理；
- **格式覆盖不变量：探针集 = 软解集**：探针格式分派（probe_raw_pixel）与
  软解格式判定/分派（soft_decodable / decode_raw_frame）逐条对应——不入
  软解支持集的格式进不了 raw 栏画面（入栏即占位错误），探针无需覆盖；
  **rawdec 新增软解格式时必须同步增加探针格式显示分支**，否则新格式栏
  可看不可探针；
- **清除时机**：进入对比、对比窗口整组滑动 / 改栏数（栏内容换血后旧探针
  坐标指向别的图）。

### 16.10 直方图覆盖层（Ctrl+H，每栏各画）

Ctrl+H 与单图模式**共用同一开关状态**（`histogram_on`）：对比模态键表补位
（Ctrl+H 带修饰键，先于"无修饰键"判定消费，否则被当编辑类组合键放行漏掉）；
退出对比后单图覆盖层跟随同一开关。

- **数据来源零额外解码**：图片栏直方图随 imgview 解码就绪（LRU 直取，同
  单图 §6.5）；raw 栏直方图由 rawdec 软解线程**顺手算**（O(像素) 被解码
  耗时掩盖，随 RawFrameTex 与纹理同源同帧）——**显示帧与直方图永远一致**
  （帧游标滑动新帧在途时保留旧帧绘制，直方图同旧，无错位），语义上跟随
  当前帧（区别于单图 raw 直方图的"首帧"）；
- **每栏各画缩小版**：尺寸按 栏宽/媒体区宽 比例缩放——直方图占所在区域的
  显示比例与单图模式一致（单图固定 320×150，对比 = 栏宽×该比例），2~6 栏
  自然逐级缩小、6 栏最小；下限 64px 防小窗下完全不可读。绘制函数
  draw_histogram 参数化（area=裁剪栏，rect=调用方算矩形），单图侧矩形
  计算抽 hist_rect_single 共用常量；
- **未就绪静默跳过**：多栏不堆"解码中…"状态文案（与单图媒体区单一状态
  行不同，n 份状态文案是噪声），直方图随各自解码完成自然浮现。
