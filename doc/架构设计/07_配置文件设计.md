## 7. 配置文件设计（config.toml，单文件集中）

```toml
codepage = "gbk"            # 非 UTF-8 字节兜底代码页（密码候选追加 + zip 老包文件名解码）
passwords = []              # 加密包密码候选列表（播放器与 VarTidy 公用，打开阶段自动探测）
log_level = "info"          # tracing 日志级别（env-filter 语法；仅重启生效）

[cache]   # dll 目录 / 解压缓存目录 / LRU 上限（max_size_mb）/ 解码块大小与块数 / 清理时机（clean_on_exit / clean_on_switch）
[media]   # video_extensions / image_extensions / file_open_depth（单媒体文件入口的目录收集深度，默认 1=只收同级；0=不限，见 4.2）
[raw]     # [[raw.demux]] 预设数组（match 通配 glob → pixfmt+宽高+fps+可选 bit_shift，格式名单见 README「raw 格式表」，链路见 13.6）——预设即裸数据唯一可见性入口，无扩展名清单；内置默认三条（*.nv12 / *.yuv400 / *.raw→bayer_auto16le+bit_shift=4），宽高可省略/0=文件名 WxH 兜底（13.6）
[player]  # hwdec / cache_secs / demuxer_max_mb / demuxer_probesize / demuxer_analyzeduration / volume / muted / mpv_log_level
[ui]      # font_path / slideshow_secs / wheel_switch_secs / ask_next_archive / sort_files（自然序，默认关=包内顺序）/ search_debounce_ms / extract_overlay_delay_ms / image_texture / image_cache_count / image_max_dim / image_full_threshold（full 触发阈值，默认 2.0）/ image_full_sharpen（full 锐化开关，默认开）——图片纹理直显，见 13.4；redraw_hover_fps（悬停移动重绘频率上限，默认 30）/ redraw_drag_fps（拖拽上限，默认 60）/ redraw_other_fps（其余情况上限，默认 60）——UI 重绘频率三档（见 13 帧呈现节奏），钳制 5~240
[extract] # prefetch_downstream_mb（下游预取上限）/ prefetch_upstream_mb（上游预取上限，见 11.1）
[vartidy] # repo_dir / report_dir（CLI 整理子命令）
[encode]  # vcodec（默认 libx264）/ crf / preset / ovcopts（编码引擎 ovcopts 追加参数，见 15.5）
```

> 约定：所有路径、阈值、扩展名列表、播放器参数均只在此文件配置，代码零硬编码。
> 格式选型：TOML（而非 JSON）——原生 `#` 注释 + 强制 UTF-8，默认配置带中文说明每个参数含义；
> 字符串必须双引号，无 YAML 裸标量陷阱（`yes/no` 变布尔、`#` 误注释）。
> 默认文件由手写模板生成（`config.rs` 的 `DEFAULT_TOML`），防漂移测试保证模板与代码默认值一致。
>
> 配置菜单与热重载（顶栏「配置」，免重启改配置）：
> - 「编辑 config.toml」：内嵌编辑器（ui/config_editor.rs）——'#' 注释灰色高亮
>   （自定义 layouter 逐行扫描，跳过双引号字符串内的 #；纯函数单测覆盖），
>   Ctrl+C/V/A/Z 为 egui 原生（另加 Ctrl+S=保存）；「保存并生效」走与启动同一
>   解析路径校验（toml::from_str::<Config>：语法与类型错均拦在写盘前），
>   通过 → 写盘 → 关窗 → 复用「重载配置」热生效；失败窗口保留并显示带行列号
>   错误（编辑内容不丢），用户删掉的键由 backfill 自动补全。
> - 「打开 config 目录」：资源管理器打开 config.toml 所在目录（外部编辑器/
>   查看备份等场景）；spawn 失败回退资源管理器定位并选中该文件。
>   顶栏提示（含"配置已重载"）无超时、与错误同槽互斥——任意鼠标点击
>   清绿（见 §14.2 顶栏消息机制）。
> - 「重载配置」：重读 config.toml 后按生效时机分三档——
>   ① 即时：media 扩展名与 ui.sort_files（`rebuild_view` 重建列表）、
>   [[raw.demux]]（可见性同走 rebuild_view，播放时现读
>   self.cfg，13.6）、codepage
>   （`vfs::set_codepage` 全局量）、ui.font_path（重装字体链）、
>   ui.image_cache_count（`ImageService::set_cap`），以及一切使用点读
>   `self.cfg` 的项（预取预算/图片阈值与锐化/幻灯片间隔等）；
>   ② 下次播放：player.*——未播放时销毁播放器（`shutdown_render` 后置 None），
>   下次播放按新配置重建；播放中不断流，仅 async 下发音量/静音；
>   ③ 仅重启：log_level（tracing 订阅器启动后固定）、cache.dll_dir（dll 启动时
>   动态加载一次）。
>   解析失败保留旧配置继续运行（编辑出错不必杀进程）。passwords/codepage 对
>   下次打开的压缩包生效（已开包的密码已锁定）。
