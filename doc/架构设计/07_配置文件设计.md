## 7. 配置文件设计（config.toml，单文件集中）

```toml
codepage = "gbk"            # 非 UTF-8 字节兜底代码页（密码候选追加 + zip 老包文件名解码）
passwords = []              # 加密包密码候选列表（播放器与 VarTidy 公用，打开阶段自动探测）
log_level = "info"          # tracing 日志级别（env-filter 语法；仅重启生效）

[cache]   # dll 目录 / 解压缓存目录 / LRU 上限（max_size_mb）/ 解码块大小与块数 / 清理时机（clean_on_exit / clean_on_switch）
[media]   # video_extensions / image_extensions / file_open_depth（单媒体文件入口的目录收集深度，默认 1=只收同级；0=不限，见 4.2）
[raw]     # [[raw.demux]] 预设数组（match 通配 glob → pixfmt+宽高+fps+可选 bit_shift，格式名单见 README「raw 格式表」，链路见 13.6）——预设即裸数据唯一可见性入口，无扩展名清单；内置默认三条（*.nv12 / *.yuv400 / *.raw→bayer_auto16le+bit_shift=4），宽高可省略/0=文件名 WxH 兜底（13.6）
[player]  # hwdec / cache_secs / demuxer_max_mb / demuxer_probesize / demuxer_analyzeduration / volume / muted / mpv_log_level
[image]   # 图片预览管线（原在 [ui] 节，键多含算法调参，独立成节）：image_texture（纹理直显开关）/ image_cache_count / image_max_dim / image_full_threshold（full 触发阈值，默认 2.0）/ image_full_sharpen（观感增强总开关，默认开）/ image_full_sharpen_amount（锐化强度，默认 1.0）/ image_full_sharpen_sigma（锐化半径 σ，默认 1.5）/ image_full_sharpen_white_edge_curve（白边抑制折点曲线 [shoot_v,ratio]：多尺度方差整数组合 shoot_v 标强边、分段线性插值 256 项 LUT 只压正向增强，默认 [100,1]→[150,0.9]→[200,0.6]→[240,0.3]→[255,0.05]（2026-11-18 用户 release 实测定版，极强边保留 5% 锐感），空=关，非法回退默认 WARN）/ image_full_sharpen_white_edge_gain（shoot 敏感度增益 1~1024 默认 1.0：乘跨尺度方差差（方向保留不取 abs，abs 实测毛躁紊乱已弃用），缓坡等边缘方差差量级小靠它展宽到曲线拐点）/ image_full_sharpen_white_edge_dilate（shoot flank 带外扩半径 0~4 默认 1：方向保留方差差响应偏在真边缘外侧 1~2px，max 膨胀外扩（1=外扩1px）覆盖边缘线本身，dump/ratio/防振铃掩码同源）/ image_full_denoise（锐化前保边降噪，默认开）/ image_full_denoise_algo（降噪算法 "guided"（默认）/"bilateral" 切换，两算法都保留各有适用图源，非法值 WARN 回退导向）/ image_full_bilateral_strength（双边 σc，默认 10）/ image_full_guided_strength（导向 ε=D² 同量纲，默认 10（用户 release 实测定版））/ image_full_guided_radius（导向窗口半径，默认 1，人像实测定版）/ image_full_antiring（防振铃：Lanczos 放大输出 clamp 回源 cell 值域剪 Gibbs 伪像、域内恒等不伤锐度，默认开，仅放大档；**边缘定向**——复用锐化链 shoot_v 掩码只处理强边 cell（≥32 ±1 膨胀），非边缘区 O(1) 跳过，依赖锐化开+白边抑制开两者齐备，缺一直通零开销）/image_full_sharpen_dump_shoot / image_full_sharpen_dump_curve / image_full_sharpen_dump_y / image_full_sharpen_dump_enhance（debug，锐化算法调试专用 sharpen 前缀：shoot 边缘图 bmp（sharpen_shoot_dump）/ 白边曲线查表文本（sharpen_curve_dump）/ 锐化输入·输出 Y 平面 bmp（sharpen_y_before/sharpen_y_after，输入为降噪后）/ 白边抑制前后增强量差异 bmp（sharpen_delta_before=amount×d 未抑制、sharpen_delta_after=amount×d×ratio 抑制后，有符号差异值整体 +128 偏移、128=零点），dump 到缓存目录 debug/ 下固定名覆盖，默认关）/ image_compare_full_resample_enable（多图对比主栏 full 重采样使能，默认关：对比目的是同屏看差异，base 档纹理已够用，full 档主栏与 base 副栏锐度不一致反而干扰判断、主栏切换逐次 full 解码纯开销；单图模式不受此键影响恒允许升级）——纹理直显链路见 13.4。旧配置 [ui] 下遗留的 image_* 键被 serde 静默忽略，缺键由 backfill 按默认值补进 [image]（个人工具不做常驻迁移代码，旧文件手动搬移一次）
[ui]      # font_path / slideshow_secs / wheel_switch_secs / ask_next_archive / sort_files（自然序，默认关=解压包包内顺序；FastSeek 包（ZIP/ISO/目录集合）不看此键强制自然序——随机访问物理序无收益；排序键=完整相对路径，同子目录连片、目录与文件名都自然序）/ search_debounce_ms / extract_overlay_delay_ms / redraw_hover_fps（悬停/滚轮重绘频率上限，默认 30）/ redraw_drag_fps（拖拽上限，默认 60）/ redraw_other_fps（其余情况上限，默认 60）——UI 重绘频率三档（见 13 帧呈现节奏），钳制 5~240
[extract] # prefetch_downstream_mb（下游预取预算，尽量取满）/ prefetch_upstream_max_mb（上游顺带落盘最大上限，伴随量非配额，实取以免费区为准，见 11.1）
[vartidy] # repo_dir / report_dir（CLI 整理子命令）
[encode]  # vcodec（默认 libx264）/ crf / preset / ovcopts（编码引擎 ovcopts 追加参数，见 15.5）
```

> 约定：所有路径、阈值、扩展名列表、播放器参数均只在此文件配置，代码零硬编码。
> 格式选型：TOML（而非 JSON）——原生 `#` 注释 + 强制 UTF-8，默认配置带中文说明每个参数含义；
> 字符串必须双引号，无 YAML 裸标量陷阱（`yes/no` 变布尔、`#` 误注释）。
> 默认文件由手写模板生成（`config.rs` 的 `DEFAULT_TOML`），防漂移测试保证模板与代码默认值一致。
>
> 配置菜单与热重载（顶栏「配置」，免重启改配置）：
> - 「编辑 config.toml」：内嵌编辑器（ui/config_editor.rs）——'#' 注释灰色高亮
>   （自定义 layouter 逐行扫描，跳过双引号字符串内的 #；纯函数单测覆盖），
>   顶部节头导航条列出全部 [section]/[[array]]（重名按出现序标 ×N），
>   点击光标落节头行并滚到该行（贴视口顶部 Align::Min；TextEdit 外部设光标不触发
>   其内部自动滚，滚动由 galley 光标坐标 + scroll_to_rect 同帧自做）；
>   Ctrl+C/V/A/Z 为 egui 原生（另加 Ctrl+S=保存）；「保存并生效」走与启动同一
>   解析路径校验（toml::from_str::<Config>：语法与类型错均拦在写盘前），
>   通过 → 写盘 → 关窗 → 复用「重载配置」热生效；失败窗口保留并显示带行列号
>   错误（编辑内容不丢），用户删掉的键由 backfill 自动补全。
> - 「打开 config 目录」：资源管理器打开 config.toml 所在目录（外部编辑器/
>   查看备份等场景）；spawn 失败回退资源管理器定位并选中该文件。
>   顶栏提示（含"配置已重载"）无超时、与错误同槽互斥——任意鼠标点击
>   清绿（见 §14.2 顶栏消息机制）。
> - 「重载配置」：重读 config.toml 后按生效时机分三档——
>   ① 即时：media 扩展名与 ui.sort_files（`rebuild_view` 重建列表）、
>   [[raw.demux]]（可见性同走 rebuild_view，播放时现读
>   self.cfg，13.6）、codepage
>   （`vfs::set_codepage` 全局量）、ui.font_path（重装字体链）、
>   image.image_cache_count（`ImageService::set_cap`），以及一切使用点读
>   `self.cfg` 的项（预取预算/图片阈值与锐化/幻灯片间隔等）；
>   ② 下次播放：player.*——未播放时销毁播放器（`shutdown_render` 后置 None），
>   下次播放按新配置重建；播放中不断流，仅 async 下发音量/静音；
>   ③ 仅重启：log_level（tracing 订阅器启动后固定）、cache.dll_dir（dll 启动时
>   动态加载一次）。
>   解析失败保留旧配置继续运行（编辑出错不必杀进程）。passwords/codepage 对
>   下次打开的压缩包生效（已开包的密码已锁定）。
>   默认模板（config.rs `DEFAULT_TOML`）以【重启生效】/【下次播放】注释标记
>   非即时项，未标记 = 重载即时生效；标记注释仅新生成的 config.toml 携带。
